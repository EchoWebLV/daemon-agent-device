X (TWITTER)

Connect your X account. Daemon writes posts from your voice — tap to approve on the device and it goes live immediately.

First-time setup — register a Daemon app on X (~3 min):

  1. Open developer.x.com/portal → Create Project → Create App inside it.
  2. In the app's User authentication settings:
    • App permissions: Read and write
    • Type of App: Native App
    • Callback URI / Redirect URL: copy from the field below
    • Website URL: any valid URL (your blog or the redirect URI)
  3. Save.
  4. Open Keys and tokens → copy the OAuth 2.0 Client ID (long string ending in :1:ci).
  5. Paste it below and tap Save.
  6. Tap Connect X, authorize on x.com, copy the code from the bounce page, paste it back, tap Finish pairing.
  7. Done — speak a post via PTT, approve on the device, it goes live.
